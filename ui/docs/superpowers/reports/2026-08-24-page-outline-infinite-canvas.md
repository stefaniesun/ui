# 整页轮廓无限画布实施报告

2026-08-24 · 分支 `feature/page-outline-infinite-canvas`

## 改动摘要

- 视图数学：新增纯 TypeScript 模块，支持 `20%–400%` 缩放钳制、适应居中、锚点缩放、视口中心保持及目标框最小可见平移，并安全处理非法数值和超大目标。
- 统一舞台：固定工具区位于画布外；原图、结构树和属性栏成为同一个 `translate3d + scale` 三栏舞台，窄屏不拆栏。
- 缩放路由：首次有效测量自动适应；画布与原图滚轮按指针缩放；树和属性栏普通滚轮保留内部滚动，`Ctrl + 滚轮` 缩放；支持缩小、放大、适应视图、`100%` 和空白双击适应。
- 平移手势：支持画布/原图空白左键、中键任意位置、非编辑焦点下空格加左键；包含 4px 阈值、指针捕获、取消/失焦/卸载清理和误点击防护。
- 定位与中心保持：视口变化保持同一舞台内容点位于视口中心；结构栏收起时舞台实际缩短，原图栏和属性栏宽度保持稳定，当前 `translate/scale` 不变；树选择元素时只平移舞台使目标框可见，图片选择仍展开祖先并滚动树行。
