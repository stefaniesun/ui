# Analysis Materializes Everything 验收报告

日期：2026-08-20

## 实现结果

- 项目文档持久化 Windows、Android、iOS 三套目标平台字体栈；未选择时 UI 仅展示 Windows 默认值，人工选择后才写盘。
- 元素分类为图标时生成 2–4 个英文关键词，本地使用 `@iconify-json/mdi` 离线检索候选。
- 图标模型结合原图裁片和候选 SVG，产出 library、crop、ambiguous 三类结构化决策。
- library 图标物化为稳定 SVG 缓存，使用 `currentColor` 避免缓存固化颜色；无效图标或模型失败安全回退原图 PNG。
- 最终整页 HTML 直接内联 library SVG；图片和回退图标继续输出 PNG 素材。
- 属性面板展示图标决策、原图裁片和 SVG 候选，人工点击后持久化为 `by: human`。
- 完成度统计覆盖区域解析、SVG 命中、PNG 回退、待确认图标、字体栈选择和未测字号。
- 未完成项只作为待办提示，不阻断整页 HTML/CSS/ZIP 输出。
