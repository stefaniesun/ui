# 整页轮廓无限画布设计

2026-08-24 · 分支 `dev`

## 1. 背景与目标

当前 `PageOutline.vue` 只让左侧原图面板通过滚动容器缩放和平移，中间结构树与右侧属性栏固定在外部。用户需要的空间模型是：顶部工具区固定，工具区下方的原图、结构树和属性栏组成一个完整工作台，由同一个无限画布统一缩放和平移。

本次目标：

1. 三栏工作台作为一个整体舞台，共享缩放和平移变换。
2. 顶部标题、统计、迁移工具与操作按钮固定，不参与画布变换。
3. 保留树节点选择、属性编辑和各面板内部滚动。
4. 首次进入自动适应视图，并提供明确的视图恢复操作。
5. 不改变整页轮廓 DTO、元素业务坐标或 PATCH 接口。

## 2. 已选方案

采用统一 DOM 舞台变换：在固定画布视口内包装完整三栏工作台，通过 `translate + scale` 控制舞台。

选择理由：

- 原图、结构树和表单仍是普通 DOM，保留文本、输入框、滚动、焦点和无障碍能力。
- 单次变换即可保证三栏严格同步缩放和平移。
- 平移不依赖浏览器滚动条，可形成向任意方向移动的无限画布体验。
- 比动态修改所有栏位尺寸更少触发布局计算，也避免使用 `<canvas>` 后重写树和表单交互。

不采用：

- 动态改变工作台宽高模拟缩放：频繁触发布局，长树和表单场景下成本较高。
- Canvas 重绘全部界面：树、输入框、文本选择和无障碍能力需重新实现，代价与风险过高。

## 3. 空间与布局

### 3.1 固定工具区

顶部现有标题、统计、迁移工具、失败区域重试及其他操作入口保持固定。画布缩放和平移不得影响工具区的位置和尺寸。

工具区补充视图控制：

- 缩小。
- 当前缩放比例。
- 放大。
- `适应视图`。
- `100%`。

### 3.2 无限画布视口

工具区下方占满页面剩余空间，作为画布视口：

- 根页面不滚动。
- 视口裁切超出边界的舞台内容。
- 画布不使用有限滚动区域模拟平移，不展示代表边界的横纵滚动条。
- 舞台可向任意方向平移，周围视觉上保留空白工作空间。
- 空白区域与舞台交互区域必须可区分，以决定左键是否可直接开始平移。

### 3.3 三栏工作台舞台

原图、结构树、属性栏组成一个完整舞台：

- 左栏仍展示整页原图、元素框和选择状态。
- 中栏仍展示可折叠结构树并支持整栏收起。
- 右栏仍展示当前元素属性并独立滚动。
- 舞台采用稳定的设计尺寸，缩放只改变视图变换，不改变业务坐标。
- 元素框继续使用相对原图的百分比坐标。
- 窄屏不再把三栏拆成上下布局；仍保留完整三栏舞台，通过适应视图、缩放和平移查看。

中栏整栏收起或恢复时，重新测量舞台尺寸，并以变化前的视觉中心为锚点校正平移，避免工作台突然跳向一侧。属性栏继续保持可见。

## 4. 视图模型

组件维护三个纯界面状态：

- `scale`：舞台缩放比例。
- `translateX`：舞台相对画布视口的水平平移。
- `translateY`：舞台相对画布视口的垂直平移。

舞台统一应用变换，变换原点固定为左上角。所有缩放入口最终经过同一套视图计算和边界钳制。

视图状态只属于当前页面会话：

- 不写入后端。
- 不修改项目数据。
- 不改变元素框坐标。
- 不在重新进入项目时恢复上次视图。

元素选择、树节点展开状态、结构栏收起状态和属性保存继续沿用当前数据流。

## 5. 初始视图与视图控制

### 5.1 首次适应视图

首次获得有效的视口尺寸和舞台尺寸后，执行一次 `适应视图`：

1. 预留统一安全边距。
2. 计算能完整容纳舞台宽高的比例。
3. 将比例限制在允许范围内。
4. 将舞台居中放入画布视口。

图片尚未加载时，可先使用工作台基础尺寸计算；图片加载导致尺寸变化后，仅在用户尚未主动操作视图时校正首次适应结果。不得在用户已缩放或平移后擅自重置视图。

### 5.2 适应视图

以下操作显式触发完整重新适应并居中：

- 点击 `适应视图`。
- 双击画布空白区域。

### 5.3 100%

点击 `100%` 将比例设置为 `1`，并保持当前画布视口中心对应的舞台内容点不变。只有尺寸无效、无法计算中心锚点时才回退到舞台居中。

### 5.4 尺寸变化

窗口、画布视口或舞台尺寸变化时：

- 首次布局执行适应视图。
- 后续变化优先保持当前视口中心对应的舞台内容点。
- 不自动回到适应比例。
- 中栏收起或恢复同样遵循保持视觉中心规则。

## 6. 缩放交互

缩放范围保持 `20%–400%`。

### 6.1 画布空白区域

- 普通滚轮以鼠标位置为锚点缩放整个舞台。
- 滚轮事件被画布消费，页面不得随之滚动。
- 双击恢复适应视图。

### 6.2 三栏面板内部

- 结构树和属性栏上的普通滚轮只滚动当前面板。
- 结构树和属性栏上的 `Ctrl + 滚轮` 以鼠标位置为锚点缩放整个舞台。
- 原图空白处普通滚轮缩放舞台。
- 原图内部不再保留只缩放左栏图片的独立缩放模型。

### 6.3 工具栏按钮

缩小和放大按钮使用固定步进，并以画布视口中心为锚点。当前比例显示经过取整，视图内部仍保留完整浮点精度。

### 6.4 锚点计算

缩放前记录锚点对应的舞台局部坐标，更新比例后重新计算平移，使该局部坐标仍位于同一个视口位置。连续滚轮事件必须使用最新视图状态，避免高频输入导致锚点漂移。

异常或非有限滚轮数据直接忽略。所有缩放结果经过范围钳制，禁止生成 `NaN` 或无限值。

## 7. 平移交互

### 7.1 画布空白区域

按住鼠标左键拖动，平移整个舞台。

### 7.2 面板和业务内容内部

为避免破坏树、表单和元素选择：

- 鼠标中键拖动可从三栏内部任意位置平移。
- 按住空格后使用左键拖动，可从三栏内部任意位置平移。
- 普通左键继续执行树节点选择、元素框选择、按钮操作、文本选择和表单编辑。
- 原图中没有元素框覆盖的空白位置可直接左键拖动。
- 元素框上普通左键用于选择；需要平移时使用中键或 `空格 + 左键`。

空格平移仅在焦点不位于输入框、文本域、选择框或可编辑内容时启用，避免输入空格时误进入平移模式。

### 7.3 拖动生命周期

- 超过最小位移阈值后才判定为拖动。
- 真正拖动后吞掉紧随其后的点击，防止误选元素或节点。
- 使用指针捕获，指针移出画布或舞台后仍可继续平移。
- `pointerup`、`pointercancel`、窗口失焦或组件卸载时必须释放拖动状态。
- 拖动期间显示 `grabbing`，可平移区域显示 `grab`。

## 8. 面板内部交互

### 8.1 原图

- 元素框、可疑状态、悬停和选中视觉保持现状。
- 点击元素框继续同步选择结构树节点。
- 树节点选中元素后，原图定位逻辑需要从“滚动左栏容器”改为校正整个舞台视图，使目标框进入画布可视区域。
- 定位只做必要平移，不改变用户缩放比例。

### 8.2 结构树

- 普通滚轮继续控制树内部滚动。
- 点击箭头只折叠或展开分支。
- 点击节点继续选择元素。
- 从图片选择隐藏后代时仍自动展开祖先并定位树行。
- 树行定位仍通过树面板自身滚动完成，不移动整个舞台。

### 8.3 属性栏

- 普通滚轮继续控制属性栏内部滚动。
- 输入、选择、按钮、文字选择和保存保持当前行为。
- `Ctrl + 滚轮` 被画布接管用于缩放，不修改字段值。
- 保存失败继续由现有状态层回滚并显示错误，画布视图不回滚。

## 9. 动效与可访问性

- 视图操作按钮提供可识别名称和当前缩放比例。
- 拖动画布不改变键盘焦点。
- 空格平移结束时恢复原有焦点语义。
- 系统启用“减少动态效果”时，适应视图、`100%` 和定位操作立即完成，不使用过渡动画。
- 默认也不依赖动画才能理解状态；如实现短暂视图过渡，必须可中断，并由统一的减少动态效果规则禁用。

## 10. 异常与边界处理

- 无法获取有效视口或舞台尺寸时，安全回退到 `100%` 居中。
- 窗口缩放、浏览器缩放和图片加载不得产生非有限视图状态。
- 舞台允许被用户拖出视口，但需保留恢复入口；`适应视图` 始终能找回完整工作台。
- 图片加载失败沿用现有错误显示，树和属性栏仍可操作。
- 属性保存失败不改变视图状态。
- 解析刷新轮廓数据时保留当前视图；只有首次建立舞台或用户显式操作时执行适应视图。

## 11. 组件边界

主要改动集中在 `apps/region-split-ui/src/components/PageOutline.vue`：

- 将工具区下方改为画布视口与统一三栏舞台。
- 以统一视图状态替换左栏滚动容器的独立缩放和平移。
- 增加适应视图、`100%`、鼠标锚点缩放和多种平移手势。
- 调整原图元素定位以适配舞台变换。
- 保留树与属性面板内部滚动。

若视图计算使组件职责明显膨胀，可提取一个只处理有限数值计算的纯 TypeScript 模块，例如视图适应、锚点缩放和中心保持。该模块不得持有业务数据或全局状态。本次不做无关重构。

`App.vue` 只在确有需要时调整承载高度或工具区布局，不改变上传、分析、项目状态和 PATCH 数据流。

## 13. 明确不做

- 不让顶部工具区参与缩放和平移。
- 不把界面重绘到 `<canvas>`。
- 不恢复旧 `PipelineCanvas` 或区域节点工作流。
- 不修改服务端 DTO、PATCH 接口或元素百分比坐标。
- 不持久化缩放和平移状态。
- 不增加分类、文字、元素框以外的属性编辑字段。
- 不实现旋转、框选、多选、迷你地图或无限画布节点编辑。
