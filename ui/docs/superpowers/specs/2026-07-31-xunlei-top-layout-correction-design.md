# 迅雷会员页顶部布局校正设计

## 目标

修复裁剪系统外壳后，会员页顶部标题、账户信息、会员页签和套餐卡的错位、截断与重影问题。390px 视口下以裁剪后的参考图为唯一视觉基准。

## 根因

- 视觉模型将连续账户文案错误拆段，并给出错误横坐标。
- 12 个月套餐区域超出 390px 逻辑画布。
- 首张套餐卡素材是包含文字的整卡截图，生成器又叠加结构化文字。
- 所有语义区域默认绘制白色背景，遮盖父级金色背景。
- 模型推断的套餐卡宽度与间距不符合参考图。

## 设计

### 语义区域背景

生成器只负责区域几何定位，`.semantic-region` 默认透明。背景、卡片、分割线等视觉效果仅由 `decoration` 内容节点绘制。这避免语义分组覆盖父级装饰背景。

### 顶部内容校正

依据裁剪后的参考图确定性校正 `visual-ir.json`：

- 标题、返回按钮与图标按参考图坐标定位。
- 账户名称作为一个连续文本节点，不拆分用户名和登录状态。
- 会员状态文案保持单行并与头像对齐。
- 页签文字和点击区域分别表达，点击区域保持透明。
- 三张套餐卡全部位于 390px 画布内，尺寸、间距和文本中心线按参考图统一校正。

### 套餐卡背景

移除包含文字的 `background-plan-gold.png` 整卡截图。选中卡使用结构化装饰节点绘制金色背景、边框和圆角；套餐期限、价格与原价仍由独立文本节点渲染，避免重影。

### 生成链路约束

- 保留页面画布同级绝对定位，不恢复父子坐标叠加。
- 非根语义区域不得自动添加不透明背景。
- 视觉内容节点必须位于逻辑画布内；严重越界继续失败关闭。
- 背景素材不得包含由独立文本节点表达的可见文案。

## 验收

- 顶部金色区域无白色语义块遮盖。
- 用户名和登录状态无异常间隔或错位。
- 三张套餐卡无截断、重影和相互覆盖。
- 390×781 浏览器中无横向溢出，顶部所有可见节点边界有效。
- 顶部参考图与页面截图按同尺寸分区比较，账户区和套餐区像素误差较修复前下降。
- `contracts`、`codegen`、`cli` 测试、`lint`、`typecheck` 与 H5 构建通过。
