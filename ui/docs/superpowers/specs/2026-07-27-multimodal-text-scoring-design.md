# 多模态文字提取与确定性评分设计

## 目标

将当前独立 OCR 裁判替换为方案 B：由已配置的多模态模型按语义区域提取文字结构，本地算法完成可复现的确定性匹配和评分。

本次变更只覆盖单状态、viewport MVP。区域粒度沿用现有 `region.bounds`，不增加 fullpage、多状态或模型直接评分能力。

## 设计决策

- 按语义区域裁图后分别调用模型，避免整页文字与区域归属不稳定。
- 参考图首次成功提取后写入冻结基线；后续迭代不得隐式更新。
- 渲染图每轮使用相同区域边界提取文字，并与冻结基线在本地匹配。
- 模型只提取结构化事实，不参与相似度判断和门禁决策。
- 任一区域提取失败时，正式门禁立即失败，不允许忽略或用空结果代替。
- 旧 stdin/stdout OCR Provider 保留为显式后备，不再是默认依赖。

## 数据合同

```ts
interface TextItem {
  text: string
  bounds: {
    x: number
    y: number
    width: number
    height: number
  }
  fontSize: number | null
  color: string | null
  confidence: number
}

interface RegionTextBaseline {
  regionId: string
  imageHash: string
  model: string
  schemaVersion: string
  promptVersion: string
  items: TextItem[]
  extractedAt: string
}
```

`bounds` 使用区域裁图内部的归一化坐标，范围为 `[0, 1]`。适配器必须拒绝非有限数值、负尺寸、越界坐标、空文字和不在 `[0, 1]` 内的置信度。

`fontSize` 和 `color` 允许模型返回 `null`，但不能省略。颜色存在时规范化为可解析的 sRGB 表示，再由本地评分转换到 Lab。

## 模块边界

### `model-adapter`

新增结构化文字提取接口，职责限定为：

- 接收单个区域图片、区域标识和提取上下文。
- 调用 OpenAI Chat Completions 兼容的多模态端点。
- 要求模型返回符合固定 JSON Schema 的 `TextItem[]`。
- 校验、规范化并返回提取结果。
- 将超时、协议错误、非结构化响应和 Schema 错误映射为稳定错误类型。

适配器不执行文字匹配、相似度计算或门禁决策。

### `visual-engine`

负责：

- 按 `region.bounds` 对参考图和渲染图裁图。
- 计算图片哈希并查询提取缓存。
- 构建和读取冻结文字基线。
- 执行文本规范化、全局最优匹配和确定性评分。
- 输出区域级文字差异及失败原因。

### CLI

负责：

- 选择默认多模态提取器或显式配置的旧 OCR 后备。
- 将模型配置和可信 Origin 配置传给适配器。
- 把文字提取失败纳入正式健康门禁。
- 在报告中呈现区域级提取状态和评分明细。

CLI 新增读取 `UI_REBUILD_MODEL_TRUSTED_ORIGINS`。该变量为逗号分隔的精确 Origin 列表；远程模型必须使用 HTTPS 且 Origin 完全匹配。loopback 地址继续按现有规则信任。

## 数据流

### 参考基线

1. 按现有语义区域边界裁剪参考图。
2. 计算区域裁图 SHA-256。
3. 查询提取缓存；未命中时调用多模态模型。
4. 校验并规范化 `TextItem[]`。
5. 保存 `RegionTextBaseline` 到 `FrozenReference`。
6. 所有区域成功后，参考文字基线才视为完整并可用于正式评分。

### 每轮评分

1. 使用与参考图相同的语义区域定义裁剪当前渲染图。
2. 查询缓存或调用模型提取 `TextItem[]`。
3. 对参考项与渲染项执行本地全局最优匹配。
4. 计算内容、位置、字号和颜色子分。
5. 合并区域分、页面文字分和现有视觉总分。
6. 任一区域失败时记录 `text-extraction-failed` 并阻断正式通过。

## 缓存

缓存键包含：

```text
区域裁图 SHA-256
+ regionId
+ 模型名
+ Schema 版本
+ Prompt 版本
```

参考图和渲染图共用相同缓存机制。模型、Prompt、Schema 或图片内容任一变化都会自然失效。缓存只保存通过 Schema 校验的成功结果；失败响应不得缓存为正常空结果。

冻结参考基线保存完整的版本与哈希信息。若运行时版本不一致，必须重新构建基线或明确失败，不能静默复用旧结果。

## 本地确定性匹配

### 文字规范化

- Unicode NFKC 规范化。
- 连续空白折叠为单个空格并去除首尾空白。
- 英文比较忽略大小写。
- 不删除标点、货币符号、小数点或日期分隔符。

置信度低于 `0.6` 的条目不进入正式匹配，并作为低置信度信息记录到报告。

### 配对

使用匈牙利算法寻找全局最小代价匹配。候选配对代价为：

```text
0.55 × 文本距离
+ 0.25 × 位置距离
+ 0.12 × 字号距离
+ 0.08 × 颜色距离
```

缺失字号或颜色时，仅对可用维度重新归一权重，避免把未知信息当作满分或零分。无法合理配对的参考项标记为缺失文字，未配对的渲染项标记为新增文字。

金额、日期、百分比、编号及纯数字属于关键文字。关键文字内容必须规范化后精确一致；不一致时内容子分为零，并在报告中突出显示。

### 区域评分

区域文字分为：

```text
0.50 × 内容分
+ 0.25 × 位置分
+ 0.15 × 字号分
+ 0.10 × 颜色分
```

字号或颜色在区域内完全不可用时，区域评分同样对剩余维度重新归一。位置基于归一化中心点和尺寸差异；颜色转换为 Lab 后使用 Delta E 计算。缺失、新增文字作为内容完整性惩罚计入内容分。

区域分按参考文字的重要性和面积进行稳定加权，最终页面文字分再通过现有视觉评分合同合并。具体合并入口沿用现有视觉引擎的权重配置，不允许模型动态修改权重。

## 错误处理

以下情况统一生成稳定的 `text-extraction-failed` 门禁失败，并保留细分原因：

- 模型请求超时或网络错误。
- HTTP 或协议响应无效。
- 返回内容不是结构化 JSON。
- JSON Schema 校验失败。
- 坐标、置信度或颜色无法规范化。
- 应处理的语义区域缺失或裁图失败。
- 冻结基线不完整或版本不兼容。

失败信息必须包含 `regionId`、阶段（参考或渲染）、稳定错误码和可读摘要，但不得写入 API Key 或完整敏感请求头。

不自动把失败降级为空文字列表，也不在正式门禁中跳过失败区域。旧 OCR 后备只有用户显式配置时才调用；后备同样必须满足统一 `TextItem[]` 合同和失败策略。

## 报告

每个区域展示：

- 提取状态、缓存命中状态和使用的模型版本。
- 内容、位置、字号、颜色子分及最终区域文字分。
- 匹配对及各自代价。
- 缺失文字、新增文字和低置信度文字。
- 关键文字不一致。
- 提取失败的稳定错误码和摘要。

报告只展示必要的诊断数据，不输出认证信息或原始模型请求。

## 测试策略

### `model-adapter`

- 合法结构化响应解析。
- 非 JSON、缺字段、非法坐标和非法置信度拒绝。
- nullable 字号与颜色规范化。
- 超时和协议错误映射。
- HTTPS 可信 Origin 精确匹配及非可信远程 Origin 拒绝。

### `visual-engine`

- 区域裁图与坐标归一化。
- 缓存命中及图片、模型、Schema、Prompt 变化导致失效。
- NFKC、空白和英文大小写规范化。
- 匈牙利匹配在输入顺序变化下保持相同结果。
- 缺失维度时权重正确重归一。
- Delta E、位置和字号评分边界。
- 关键文字要求精确一致。
- 缺失、新增和低置信度条目惩罚。
- 任一区域提取失败时正式门禁失败。

### CLI 与集成

- 默认选择多模态提取器。
- 显式配置时使用旧 OCR 后备。
- `UI_REBUILD_MODEL_TRUSTED_ORIGINS` 正确传递。
- 冻结参考基线跨轮复用且不被候选结果覆盖。
- 报告包含区域级分项与失败信息。
- 现有单状态 viewport 流程保持通过，多状态和 fullpage 仍被明确拒绝。

## 验收标准

- 不配置独立 OCR Provider 时，已配置的多模态模型可完成参考图和渲染图文字提取。
- 同一组结构化提取结果在重复运行及输入顺序变化后得到相同匹配和评分。
- 参考基线被冻结并具有可验证的缓存版本信息。
- 任一区域提取失败都会阻断正式门禁并产生可定位报告。
- 远程模型仅在 HTTPS Origin 明确列入可信列表时可用。
- 现有视觉流程、类型检查、lint 和测试继续通过。

## 非目标

- 不让模型直接判断文字相似度或最终验收结果。
- 不实现全文语义理解、翻译容错或同义词匹配。
- 不增加 fullpage、多状态或跨 viewport 基线。
- 不自动修正文案。
- 不移除旧 OCR Provider；仅将其降级为显式后备。
