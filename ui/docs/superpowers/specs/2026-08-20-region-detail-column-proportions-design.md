# 区域详情三栏比例布局设计

## 目标

按参考图重新分配区域详情内部宽度，使元素树、元素属性和 AI 结构校准三块空间均衡，避免元素属性栏过窄。

## 布局比例

工作区采用三列：

- 元素树列：36%。
- 元素属性列：36%。
- AI 结构校准列：28%。

上方区域图片横跨前两列。下方元素树和元素属性分别占据前两列；AI 结构校准占第三列并贯穿上下两行。

## 高度与图片

- 工作区继续固定为 500px。
- 上方图片区约占 65%，下方元素编辑区约占 35%。
- 区域图片保持等比例完整适配，不出现横向或纵向滚动条。
- 元素树、元素属性、AI 对话只在各自内部滚动。

## 验证

- 布局契约测试验证图片区跨前两列，三块面板分别位于正确网格区域。
- 前端全量测试、类型检查和生产构建通过。
- 真实页面确认三栏宽度接近 36% / 36% / 28%，属性表单不再被挤窄。
