# 区域列表边界调整按钮设计

## 背景

区域列表当前在每个区域右侧展示 AI 置信度百分比。该数值对当前人工校正流程帮助有限，因此将其从界面移除，并利用原位置提供直接调整区域上下边界的操作。

## 目标

- 不再展示区域置信度百分比。
- 每个区域列表项提供上、下两个边界调整按钮。
- 用户无需先选中区域即可直接调整，点击按钮时自动单选对应区域。
- 保持区域连续覆盖图片，不产生空隙、重叠或越界。
- 复用现有撤销、重做和防抖持久化能力。

## 非目标

- 不删除分析结果中的 `confidence` 字段，也不修改模型提示词或 API 数据结构。
- 不改变 AI 分析流程或候选线算法。
- 不增加边界拖拽功能。
- 不调整区域最小高度规则。

## 列表交互

每个区域列表项右侧删除百分比，替换为两个紧凑按钮：

- `▲`：将当前区域上边界向上移动，使当前区域向上增加高度；前一区域同步缩小。
- `▼`：将当前区域下边界向下移动，使当前区域向下增加高度；后一区域同步缩小。

按钮使用明确的无障碍名称，分别表达“向上扩展区域”和“向下扩展区域”。按钮操作阻止事件冒泡，不能触发行多选、双击重命名等行为。

点击任一按钮时，先将对应区域设为唯一选中区域，再执行边界调整。画布和列表选择态立即同步。

## 调整步长与长按

- 单击一次移动 `1px` 原图坐标。
- 按住按钮 `400ms` 后进入连续调整。
- 连续调整期间每 `60ms` 移动 `1px`。
- 松开指针、指针离开按钮或组件卸载时停止连续调整。
- 长按后抑制尾随 click，避免额外移动一次。

## 边界规则

区域上下边界由相邻区域共享，调整时必须同时补偿相邻区域：

- 上边界上移：前一区域高度减少 `1px`，当前区域起点上移且高度增加 `1px`。
- 下边界下移：当前区域高度增加 `1px`，后一区域起点下移且高度减少 `1px`。

继续使用 `MIN_REGION_HEIGHT = 8`：

- 第一块区域没有可向上扩展的前一区域，禁用 `▲`。
- 最后一块区域没有可向下扩展的后一区域，禁用 `▼`。
- 前一区域已达到 `8px` 时，禁用当前区域的 `▲`。
- 后一区域已达到 `8px` 时，禁用当前区域的 `▼`。
- 核心边界算法仍执行钳制，作为 UI 禁用逻辑之外的数据安全保障。

## 状态接口

在前端 store 增加按区域索引和边界方向调整的明确接口，而不是由列表组件直接修改区域数组：

- 上边界调整映射到前一区域与当前区域的共享边界。
- 下边界调整映射到当前区域与后一区域的共享边界。
- 状态层负责选择目标区域、创建撤销快照、调用核心边界操作并安排持久化。

核心层继续以“移动相邻区域共享边界”为基础能力；前端状态层负责将“当前区域向上/向下扩展”的 UI 语义映射到正确的边界索引和位移方向。

## 撤销与持久化

- 单次点击形成一次可撤销调整。
- 同一轮连续长按的调整沿用现有 `500ms` 微调合并窗口，作为一个撤销步骤。
- 调整继续使用现有 `400ms` 防抖持久化，避免长按期间频繁请求服务端。
- 撤销、重做后仍立即持久化。

## 禁用状态

以下情况下两个按钮均禁用：

- 应用处于 busy 状态。
- AI 分析尚未完成。
- 当前处于拆分模式。

此外，各方向按钮根据首尾位置及相邻区域最小高度独立禁用。

## 组件职责

### `RegionList.vue`

- 删除置信度百分比展示。
- 渲染上下边界按钮。
- 管理按钮的 pointer 长按计时和尾随 click 抑制。
- 调用 store 的区域边界调整接口，不直接修改区域数据。

### `state.ts`

- 提供按目标区域和方向执行调整的接口。
- 自动单选目标区域。
- 将 UI 方向映射到核心共享边界操作。
- 复用撤销合并和防抖持久化流程。
- 提供或支持每个方向的可用性判断。

### 核心区域操作

- 继续保证最小高度、连续覆盖、无重叠和无空隙。
- 如现有接口足以表达两类操作，则不增加重复算法。

## 错误与边界处理

- 达到边界极限时操作为 no-op，不能产生非法数据。
- no-op 不应创建无意义的撤销快照或持久化请求。
- 连续操作期间即使达到极限，也应安全停止产生数据变化。
- 组件卸载时必须清理全部计时器。

## 测试范围

### 列表组件

- 不再渲染置信度百分比。
- 每行显示 `▲`、`▼` 按钮及无障碍名称。
- 点击按钮自动单选对应区域。
- 点击按钮不触发行点击、多选或重命名。
- 第一行 `▲`、最后一行 `▼` 正确禁用。
- 相邻区域达到最小高度时对应方向禁用。
- busy、未分析和拆分模式下按钮禁用。
- 长按时遵循 `400ms` 延迟和 `60ms` 重复间隔，并抑制尾随 click。

### 状态层

- 向上扩展时正确移动当前区域上边界并补偿前一区域。
- 向下扩展时正确移动当前区域下边界并补偿后一区域。
- 自动单选目标区域。
- 保持区域不变量。
- 连续长按可通过一次撤销恢复。
- no-op 不增加撤销记录或持久化任务。

### 回归验证

- 现有画布覆盖层随区域边界实时更新。
- 键盘微调、工具栏操作、拆分、合并、重命名、撤销和重做仍正常工作。
- 全量测试、类型检查和生产构建通过。

## 验收标准

1. 区域列表不再显示置信度百分比。
2. 每个区域右侧显示上、下箭头按钮。
3. 单击按钮自动选择该区域并按对应方向扩展 `1px`。
4. 长按按钮按既定节奏连续调整，松开后立即停止。
5. 首尾区域和最小高度限制正确反映为按钮禁用状态。
6. 任意操作后区域始终连续覆盖整张图片，且每块高度不小于 `8px`。
7. 单次连续长按可以通过一次撤销完整恢复。
8. 调整被正常持久化，且不会在长按期间产生高频服务端请求。
