# 整页轮廓三栏布局设计

2026-08-21 · 分支 `dev`

## 1. 背景与目标

当前 `PageOutline.vue` 使用两栏布局：左侧整页原图，右侧结构树与校准表单上下堆叠。结构浏览和属性编辑互相挤压，选中、定位、校准的操作链不连贯。

本次改为三栏工作区：

1. 左栏展示整页原图和元素框。
2. 中栏展示可折叠结构树，并支持整栏收起。
3. 右栏独立展示当前选中元素的属性编辑区。

目标是让用户同时看到“原图位置、结构关系、当前属性”，减少滚动和上下文切换。

## 2. 已选方案

采用方案 B：可收起结构栏。

默认显示三栏。中栏既支持节点级展开/折叠，也支持整栏收起。整栏收起后，左栏自动占用释放的空间，右栏保持可见。

未采用的方案：

- 固定三栏：实现直接，但持续压缩原图空间。
- 结构抽屉：原图空间最大，但结构树会遮挡内容，频繁对照时需要反复开关。

## 3. 布局与职责

### 3.1 顶部工具栏

保留当前整页标题、可疑项数量、解析进度、错误信息和失败区域重试入口。工具栏不参与三栏滚动。

### 3.2 左栏：整页原图

左栏保留现有整页图片、全部元素框、可疑项高亮、选中高亮和悬停联动。

交互规则：

- 点击元素框，选中对应元素。
- 选中后，中栏自动定位对应树行。
- 如果对应树行位于已折叠分支内，先自动展开其全部祖先，再滚动定位。
- 当中栏整栏收起时，点击元素框只更新选中状态；再次展开中栏后，应能看到已选中的树行。

### 3.3 中栏：可折叠结构树

中栏根据现有 `PageOutlineElement.parentHint` 和元素顺序构建可见树，不修改后端 DTO。

节点交互：

- 有子节点的行显示展开箭头。
- 点击箭头只切换展开状态，不改变当前选择。
- 点击树行选中元素，并让左栏元素框滚动到可视区域。
- 折叠节点后隐藏全部后代，但不删除数据或改变服务端层级。
- 若当前选中元素因祖先折叠而被隐藏，选择状态保留；后续从图片再次选择该元素时自动展开祖先。

整栏交互：

- 树栏标题区提供明确的收起按钮。
- 收起后保留一个窄恢复控制条，用户可随时展开。
- 收起状态仅属于当前页面会话，不持久化到项目数据。

树行继续展示层级编号、名称、分类和可疑状态。

### 3.4 右栏：选中元素属性

右栏固定独立存在并独立滚动，不再与结构树上下堆叠。

本轮“区域属性”定义为当前选中的元素或节点属性。可编辑字段严格保持现有 PATCH 接口范围：

- 分类 `kind`
- 文字 `text`
- 元素框 `x / y / w / h`

右栏同时只读展示元素名称、层级编号、所属区域和可疑状态，帮助用户确认编辑对象。

本轮不增加顶层 Region 属性编辑，不增加颜色、字体、圆角、滚动、图标挑选等旧详情字段，也不扩展服务端 PATCH 契约。

未选中元素时，右栏显示空状态提示，不展示可提交表单。

## 4. 状态与数据流

三栏继续共享父组件传入的 `selectedId` 和 `hoveredId`：

1. 左栏或中栏触发 `select(id)`。
2. `PageOutline.vue` 发出已有 `select` 事件。
3. 上层状态更新 `selectedId`。
4. 左栏、中栏、右栏根据同一个 `selectedId` 同步高亮和表单内容。

组件内部新增两类纯 UI 状态：

- `collapsedIds`：已折叠节点 ID 集合。
- `treePanelCollapsed`：结构栏是否整体收起。

组件根据 `parentHint` 建立父子索引和祖先链，计算当前可见树行。该计算只影响渲染，不改变 `outline.elements`。

属性保存继续发出已有 `patch` 事件。乐观更新、服务端持久化和失败回滚继续由现有 `page-outline-state.ts` 负责。

## 5. 错误与边界处理

- `parentHint` 为空、指向不存在元素或形成异常关系时，该元素按顶层节点显示，避免整棵树不可用。
- 图片选择的元素无法找到祖先链时，仍选中元素，并尽可能滚动到已有树行。
- 保存失败时沿用现有错误展示和状态回滚，不清空用户选择。
- 解析进行中时三栏仍可浏览当前已有轮廓；解析结束后使用最新轮廓刷新。
- 系统启用减少动态效果时，不添加栏位过渡动画或平滑滚动。

## 6. 响应式行为

桌面宽度下使用三栏：左栏弹性占据剩余空间，中栏和右栏使用受控宽度。

窄屏下保持功能优先：

- 原图在上方。
- 结构树和属性区在下方并排；空间不足时上下排列。
- 节点折叠和整栏收起仍可使用。
- 不通过覆盖式抽屉遮挡原图。

具体断点沿用组件现有约 `900px` 的响应式边界，可在实现时根据真实浏览器效果小幅调整。

## 7. 组件边界

主要修改集中在 `apps/region-split-ui/src/components/PageOutline.vue`：

- 将两栏 CSS Grid 改为三栏布局。
- 增加折叠状态和可见节点计算。
- 拆分树行的箭头操作与选择操作。
- 增加结构栏整体收起/恢复控制。
- 将校准表单迁移为独立右栏，并补充只读上下文。

如模板复杂度明显上升，可提取仅负责渲染和交互的内部组件，但不引入新的全局状态或后端接口。本次不做无关重构。

## 8. 测试与验收

在 `PageOutline.test.ts` 增加以下行为测试：

1. 默认渲染左、中、右三栏。
2. 点击父节点箭头隐藏后代，再次点击恢复后代。
3. 点击箭头不改变当前选择。
4. 从图片选择折叠分支中的后代时，自动展开祖先并定位树行。
5. 点击树行仍能选中并定位原图框。
6. 整体收起结构栏后，原图栏扩展且右侧属性栏保持显示；恢复后保留选择。
7. 右栏只编辑现有 `kind/text/box` 字段，并发出原有 PATCH 载荷。
8. 未选中元素时显示空状态。
9. 可疑项、悬停联动、失败重试和解析进度不回归。

完成单元测试、前端类型检查和构建后，必须在真实浏览器验证：

- 三栏宽度和独立滚动是否合理。
- 中栏收起后原图是否实际扩展。
- 树与图片双向定位是否连贯。
- 长树、长属性内容和窄屏布局是否可用。

## 9. 明确不做

- 不修改 `PageOutline` 服务端 DTO。
- 不新增 Region 属性编辑 API。
- 不恢复逐区域详情工作流。
- 不增加分类、文字、元素框之外的编辑字段。
- 不持久化树节点或结构栏的折叠状态。
- 不引入覆盖原图的结构抽屉。
