# 隐藏候选分隔线设计

## 目标

去掉区域分析图中的金色候选分隔线，减少对原图和实际区域边界的视觉干扰。

## 设计

- `RegionCanvas` 不再绘制候选分隔线，也不再提供候选线显示开关。
- 蓝色实际区域边框、区域名称标签、选中和悬停效果保持不变。
- 候选线数据及其计算逻辑继续保留。
- 用户进入拆分模式时，拆分位置仍通过候选线完成智能吸附。
- 不修改核心分析算法、store 公共接口、API 或区域坐标换算。
- 清理仅用于控制候选线可见性的组件 props 和 App 状态，保留拆分吸附所需的数据传递。

## 验收标准

1. 普通浏览和拆分模式下均不显示金色候选分隔线。
2. 实际区域蓝色边框和标签正常显示。
3. 拆分线仍能吸附到候选位置。
4. 区域选择、拆分、合并、微调、缩放坐标不受影响。
5. 相关测试、类型检查和生产构建通过。
