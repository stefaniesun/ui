# 区域详情完整适配布局设计

## 目标

区域详情保持当前固定高度。区域图片在图片区内等比例完整显示，不出现横向或纵向滚动条；元素标注、框选和取色坐标仍与图片精确对应。

## 布局

- 工作区继续采用两列结构：左侧主内容，右侧 AI 结构校准。
- 左侧主内容采用上下结构：上方区域图约占 65%，下方元素树与属性约占 35%。
- AI 栏宽度调整为 300px，输入区保持在底部。
- 详情节点总高度保持 500px，避免影响画布节点避让与连线。

## 图片适配

`ElementOverlay` 的舞台不再固定占满容器宽度，而是在可用图片区内按区域原始宽高比进行 contain 计算。舞台宽高始终同时小于等于图片区可用宽高，并在容器内水平、垂直居中。

图片、元素框、拖拽框和取色事件仍共享同一个舞台坐标系，因此缩放后不需要单独修正标注位置。

## 溢出策略

- 区域图片区使用 `overflow: hidden`，禁止自身产生滚动条。
- 元素树、属性和 AI 对话各自在内部滚动。
- 不裁切区域图片，不拉伸图片，不改变图片宽高比。

## 验证

- 组件测试验证图片区不再使用滚动容器，并验证舞台采用可用空间完整适配结构。
- 前端全量测试、类型检查和生产构建通过。
- 真实页面确认区域图片完整可见、无横纵滚动条，元素框仍与原图对齐。
