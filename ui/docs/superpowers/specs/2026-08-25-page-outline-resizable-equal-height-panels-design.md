# 整页轮廓等高可调分栏设计

2026-08-25 · 分支 `dev`

## 1. 背景与目标

当前整页轮廓已将原图、结构树和属性栏放入统一无限画布舞台，但舞台高度会被长图撑开，结构树与属性栏随之变高；三栏宽度也由固定 Grid 列定义，用户不能调整。

本次目标：

1. 三栏保持同一高度，高度等于顶部工具区下方的画布可视高度。
2. 原图、结构树和属性栏内容超高时分别在栏内纵向滚动。
3. 增加两条分隔线，自由调整三栏宽度。
4. 调宽期间保持舞台总宽、当前缩放比例和视觉中心稳定。
5. 保留无限画布、元素选择、树节点选择、属性编辑及结构栏收起行为。

## 2. 已选方案

采用 CSS Grid 配合两条自定义 Pointer Events 分隔线。

选择理由：

- 能精确控制相邻栏宽度、最小宽度和舞台总宽。
- 可阻止分隔线事件进入无限画布手势，避免误平移和误点击。
- 无需增加第三方依赖，符合当前组件的事件与状态模型。
- 比 CSS `resize` 更容易保证两侧此消彼长及双击复位。

不采用：

- 第三方分栏组件：增加依赖，且事件模型可能与画布平移冲突。
- CSS `resize`：难以同时保证相邻栏联动、最小宽度和舞台总宽固定。

## 3. 等高与滚动布局

### 3.1 共同高度

画布视口占据顶部工具区下方的剩余页面高度。三栏舞台的布局高度取画布视口的可视高度，不再由原图宽高比或任一栏内容高度撑开。

舞台接受无限画布的统一 `translate + scale` 变换。这里的“可视高度”指变换前的舞台布局高度；缩放后屏幕上的实际显示高度随舞台比例变化。

浏览器窗口、顶部工具区或画布视口高度变化时，重新测量共同高度。高度变化不得重置栏宽或用户的缩放比例。

### 3.2 独立滚动

三栏分别形成独立纵向滚动容器：

- 原图栏滚动整页图片及元素框。
- 结构树栏只滚动树内容，栏头和收起按钮保持在栏内顶部。
- 属性栏滚动属性内容。

三栏内部普通滚轮滚动当前栏；`Ctrl + 滚轮`交给无限画布，以鼠标位置为锚点缩放整个舞台。滚动不得串联到页面根容器。

选中树节点需要展示对应元素时，优先滚动原图栏使元素框进入原图栏可视区域，不再通过移动整个舞台追踪图片内部的纵向位置。树节点自身定位继续滚动结构树容器。

## 4. 可调分栏

### 4.1 分隔线

三栏之间增加两条可拖动分隔线：

1. 第一条位于原图与结构树之间，重新分配这两栏的宽度。
2. 第二条位于结构树与属性栏之间，重新分配这两栏的宽度。

每次拖动只改变分隔线两侧的相邻栏，两侧宽度此消彼长。舞台总宽保持不变，分隔线自身占用固定布局宽度并计入总宽。

### 4.2 宽度限制

最小宽度为：

- 原图栏：`320px`。
- 结构树栏：`220px`。
- 属性栏：`220px`。

当继续拖动会使任一相邻栏低于下限时，将结果钳制在边界。另一栏没有独立固定最大值，其最大值由舞台总宽、其他栏最小宽度和分隔线宽度共同决定。

若窄屏下舞台默认宽度不足以同时满足三个最小宽度，则舞台基础宽度至少扩大到可满足全部下限；无限画布通过适应视图展示完整舞台，不把三栏改成上下布局。

### 4.3 默认值与复位

首次进入采用当前三栏默认比例，并把分隔线宽度计入舞台总宽。栏宽仅属于当前页面会话，不写入后端或本地持久化。

双击某条分隔线时，仅恢复该边界相关栏位的默认分配，同时遵守第三栏当前宽度及所有最小宽度限制。复位不改变当前缩放比例。

## 5. 拖动交互

- 分隔线及其命中区显示 `col-resize` 光标。
- `pointerdown` 后捕获指针，移出舞台仍能继续调整。
- `pointermove` 使用拖动开始时的相邻栏宽与指针位置计算结果，避免累计误差。
- `pointerup`、`pointercancel`、窗口失焦或组件卸载时释放捕获并清理状态。
- 分隔线事件阻止默认行为和冒泡，不触发画布平移、元素框点击、树选择或文本选择。
- 拖动期间不添加宽度过渡，保证分隔线紧跟指针。
- 系统启用“减少动态效果”时同样立即更新，不依赖动画表达状态。

分隔线应提供足够的可命中宽度和可识别名称；视觉线可以窄于命中区。现有中键拖动和`空格 + 左键`平移仅在分隔线之外生效。

## 6. 无限画布协作

调整栏宽时：

- 舞台总宽不变。
- 当前 `scale` 不变。
- 画布视口中心对应的舞台内容点保持不变。
- 不自动执行“适应视图”。

用户显式点击“适应视图”或双击画布空白区域时，使用当前舞台宽高重新计算。`100%`继续保持当前视口中心。

三栏内部普通滚轮全部用于栏内滚动，因此原图栏与结构树、属性栏规则一致；只有画布空白处普通滚轮或三栏内`Ctrl + 滚轮`执行舞台缩放。

## 7. 结构栏收起与恢复

结构栏收起功能保留：

- 收起前记录原图、结构树和属性栏宽度。
- 收起后移除结构树以及与其相邻的两条分隔线，显示现有结构恢复条。
- 原图栏和属性栏沿用收起前各自宽度，不因收起而重新分配。
- 舞台总宽随被移除的结构栏和分隔线缩小，并沿用现有保持画布视觉中心规则。
- 恢复后还原收起前的三栏宽度和两条分隔线，并继续定位当前树节点。

结构栏收起期间不允许调整隐藏栏宽。

## 8. 状态与组件边界

主要改动集中在 `apps/region-split-ui/src/components/PageOutline.vue`：

- 增加三栏宽度和分隔线拖动状态。
- 将固定 Grid 列改为状态驱动的列模板。
- 将舞台高度绑定到有效画布可视高度。
- 为原图栏增加独立纵向滚动，并调整元素定位逻辑。
- 保持结构树与属性栏现有业务数据流。

宽度钳制和相邻栏重新分配应提取为纯 TypeScript 计算，便于覆盖边界测试；该模块不持有 DOM、业务数据或全局状态。不做无关组件重构。

## 9. 异常与边界处理

- 无法获取有效视口高度时使用安全基础高度，后续测量有效后再校正。
- 非有限指针坐标或栏宽输入直接忽略，不得产生 `NaN`、负宽度或无限宽度。
- 指针取消或组件卸载后不得留下调整光标或活跃拖动状态。
- 图片加载失败不影响结构树、属性栏或分栏调整。
- 属性保存失败不回滚栏宽与画布视图。
- `适应视图`始终可以从任意栏宽、缩放和平移状态找回完整舞台。

## 10. 测试与验收

### 10.1 自动化测试

覆盖：

1. 三栏布局高度等于画布视口有效高度。
2. 原图、结构树和属性栏分别形成独立滚动容器。
3. 三栏内普通滚轮不缩放舞台，`Ctrl + 滚轮`缩放舞台。
4. 第一条分隔线只重新分配原图与结构树宽度。
5. 第二条分隔线只重新分配结构树与属性栏宽度。
6. 调整前后舞台总宽保持不变。
7. 三栏分别钳制在 `320px`、`220px`、`220px`下限。
8. 分隔线使用指针捕获，并在结束、取消和卸载时清理。
9. 拖动分隔线不触发画布平移、树选择或元素选择。
10. 双击分隔线恢复对应默认分配。
11. 结构栏收起后保留原图与属性栏宽度，恢复后还原三栏宽度。
12. 调宽时缩放比例与视觉中心保持稳定。
13. 调宽后“适应视图”、`100%`和画布恢复行为正确。
14. 树选择元素后滚动原图栏展示元素框，并保持舞台视图不变。
15. 非有限输入和无效高度安全回退。
16. 现有无限画布、树折叠、选择联动和属性编辑测试继续通过。

### 10.2 工程验证

- 前端单元测试。
- TypeScript 类型检查。
- 生产构建。
- 修改文件静态诊断。

### 10.3 真实浏览器验收

必须验证：

- 桌面与窄屏下三栏严格等高。
- 三栏内容超高后各自显示并使用纵向滚动条。
- 两条分隔线拖动流畅，移出舞台后仍可继续，释放后无黏滞状态。
- 三栏无法被压缩到最小宽度以下。
- 拖动分隔线不移动无限画布，也不误选节点或元素。
- 普通滚轮滚动悬停栏，`Ctrl + 滚轮`缩放整个舞台。
- 结构栏收起与恢复时栏宽和视觉中心符合设计。
- 调宽后适应视图、`100%`、平移、缩放和元素定位正常。
- 输入框、按钮、树节点、元素框和文本选择无回归。
- 浏览器控制台无错误。

## 11. 明确不做

- 不允许任一栏拖到 `0px`或通过分隔线完全隐藏。
- 不持久化栏宽。
- 不改变后端 DTO、PATCH 接口或元素百分比坐标。
- 不增加横向栏内滚动作为宽度调整替代方案。
- 不引入第三方分栏组件。
- 不改变顶部工具区固定、舞台统一缩放和平移的整体空间模型。
