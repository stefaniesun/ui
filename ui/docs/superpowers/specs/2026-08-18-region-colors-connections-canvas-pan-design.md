# 区域配色、连线稳定性与画布拖动设计

## 目标

修复区域画布的三个关联问题：为每个区域提供独立且稳定的视觉颜色；确保每个已打开详情节点始终与对应区域保持连线；允许用户在工作区节点内容中的非交互空白处拖动无限画布。

## 区域颜色模型

新增统一的区域视觉颜色函数，以 `region.id` 做稳定哈希并映射到深色界面下具有足够对比度的调色板。

颜色规则：

1. 同一个区域 ID 在原图区域框、分析图覆盖框、列表编号与端口、连线、详情节点边框和输入端口中使用同一种颜色。
2. 区域排序、详情打开顺序和页面刷新不改变颜色。
3. 不同区域优先使用不同颜色；区域数量超过调色板容量时允许循环使用。
4. 选中和悬停状态通过透明度、背景、阴影或线宽表达，不替换区域基础色。
5. 颜色映射是纯函数，不写入区域业务数据或后端文档。

建议新增 `region-visual.ts`，提供：

```ts
regionColor(regionId: string): string
regionSoftColor(regionId: string): string
```

所有组件直接通过同一函数或上层传入的颜色获取视觉身份，避免重复实现。

## 颜色应用范围

### `RegionCanvas.vue`

每个区域覆盖层设置 CSS 自定义属性 `--region-color` 和 `--region-soft-color`。边框使用区域色，背景使用对应透明色；悬停或选中时增加不透明度和阴影。

### `RegionList.vue`

每行设置区域颜色变量。编号、右侧连接端口和选中边框使用区域色；选中背景使用区域柔和色。区域类型文字保持中性色，避免界面过度彩色化。

### `PipelineCanvas.vue`

每条连线保存区域颜色并直接设置 SVG `stroke`。连线身份由 `region.id` 确定，不依赖详情节点打开顺序。

### `PipelineNode.vue`

增加可选 `accentColor`。详情节点通过 CSS 自定义属性将区域色应用到输入端口、状态点、定位高亮和顶部边框。工作区与代码节点未传颜色时继续使用全局主题色。

## 连线稳定性

当前连线起点来自区域列表行 DOM，终点来自详情节点位置。改造后仍保持该模型，但补齐刷新和恢复机制。

触发重新测量的场景：

- 打开或定位详情节点后；
- 区域列表滚动；
- 区域列表内容、尺寸或位置变化；
- 工作区节点拖动；
- 详情节点拖动；
- 画布缩放和平移；
- 浏览器窗口尺寸变化；
- 图片加载完成及分析结果更新。

使用 `requestAnimationFrame` 合并高频刷新。区域行暂时无法测量时，不删除区域与详情节点的逻辑连接关系；只暂停该路径渲染。后续刷新一旦取得锚点立即恢复连线。

为避免连线起点位于被裁剪区域或滚动容器外，只有区域行在列表可视区域内时使用行端口作为起点；不可见时使用区域列表容器右边缘的上/下边界代理锚点，使连线仍然可见并表达连接方向。

## 画布拖动

画布平移从“只能在画布根或点阵背景开始”改为“在非交互元素上可以开始”。

允许开始平移：

- 画布背景；
- 工作区节点内容中的纯空白容器；
- 区域列表右侧或底部空白区域；
- 不承载按钮、输入、图片标注或列表行操作的空白。

禁止开始平移：

- `button`、`input`、`select`、`textarea`、`a`；
- 区域列表行及连接端口；
- 图片和区域标注层；
- 可滚动容器的滚动条操作；
- 节点标题栏，标题栏继续负责拖动节点本身。

通过 `data-canvas-pan` 标记明确允许的容器，通过 `data-no-canvas-pan` 标记交互区域。画布使用事件冒泡识别最近标记，不再由 `RegionsNode` 根节点无条件阻止所有 `pointerdown`。

拖动空白处只修改 `viewport.x/y`，不会移动工作区节点位置。

## 组件边界

- `region-visual.ts`：唯一负责稳定颜色分配。
- `RegionCanvas.vue`、`RegionList.vue`：应用区域颜色并提供列表锚点。
- `RegionsNode.vue`：转发布局变化，不保存坐标或颜色状态。
- `PipelineCanvas.vue`：连线测量、代理锚点、视口平移和动态详情节点。
- `PipelineNode.vue`：通用节点颜色表达，不理解区域业务对象。

## 异常与降级

- 缺少 `ResizeObserver` 时，依赖滚动、窗口 resize、图片加载和用户画布交互刷新连线。
- 区域行和列表容器都无法测量时，暂不渲染该路径，节点仍正常显示。
- 颜色函数接收到空 ID 时回退到全局强调色。
- 指针事件目标不是 `Element` 时按画布背景处理。

## 测试范围

1. 相同区域 ID 在多组件中取得相同颜色，不同区域优先不同色。
2. 区域重新排序和详情打开顺序不改变颜色。
3. 区域框、列表端口、连线和详情节点使用对应区域色。
4. 打开多个详情节点时，每个区域都有独立连线。
5. 列表滚动后连线起点重新计算；不可见行使用列表边界代理锚点。
6. 画布缩放、平移和节点拖动后连线保持对应。
7. 工作区空白处可以拖动画布。
8. 点击区域行、按钮、图片、表单和节点标题栏不会误触画布平移。
9. 空白拖动只改变视口，不改变工作区节点位置。
10. 现有区域选择、详情创建、节点拖动和列表滚动行为保持通过。
