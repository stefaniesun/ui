# 区域识别详情动态布局设计

## 目标

仅调整区域识别详情内部布局，不影响画布上的其他节点。用户可拖动三条分隔线，并看到、保存最终比例值；所有区域详情共用同一组比例。

## 可调区域

1. 区域图片与下方元素区之间的水平分隔线：调整图片区和元素区高度。
2. 元素树与元素属性之间的垂直分隔线：调整两者宽度。
3. 元素属性与 AI 结构校准之间的垂直分隔线：调整前两列总宽度和 AI 区宽度。

区域图片继续等比例完整适配，不出现横向或纵向滚动条。

## 数值与持久化

顶部实时显示：

`图片 65% / 元素 35%｜树 36% / 属性 36% / AI 28%`

比例写入浏览器 `localStorage`，所有区域详情实例读取同一份配置。提供“重置布局”按钮恢复默认值。

## 约束

- 图片高度：35%–80%。
- AI 宽度：18%–45%。
- 元素树和属性区各不小于 15%。
- 三列宽度始终合计 100%。
- 拖动期间禁止文本选择，并使用对应方向的调整光标。
- 键盘可聚焦分隔线，方向键微调比例。

## 默认值

- 图片 65%，元素 35%。
- 元素树 36%，元素属性 36%，AI 28%。
