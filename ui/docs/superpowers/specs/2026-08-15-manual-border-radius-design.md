# 手动圆角设计

日期：2026-08-15

## 目标

停止依赖效果不稳定的像素圆角识别。新检测的元素默认均为直角，仅允许用户在右侧属性面板为 `image` 和 `component` 元素手动开启圆角。

## 数据契约

继续复用可选字段 `ElementNode.style.borderRadius`，不新增开关字段：

- 字段不存在或值为 `0`：圆角关闭。
- 正整数：圆角开启，数值即圆角像素值。

前端关闭圆角时删除该字段，避免同时维护开关和值两份重复状态。

## 检测行为

元素自动检测不再调用圆角测量，也不再向任何新节点写入 `style.borderRadius`。现有圆角测量原语可以保留，避免扩大本次改动范围，但不参与默认检测管线。

## 属性面板交互

只有 `image` 和 `component` 元素显示圆角设置：

- 元素数据加载后圆角开关默认关闭。
- 用户首次人工开启时写入默认值 `8px`。
- 开启后显示圆角数值输入与现有增减操作。
- 关闭时删除 `style.borderRadius`。
- `grid`、`text`、`icon`、`decoration` 不显示圆角设置。

## 旧数据迁移

- 元素数据载入前端 Store 时，删除所有节点已有的 `style.borderRadius`，包括 `image` 和 `component`。
- 清理后的内存状态立即作为属性面板和叠加预览的数据源，因此所有旧元素均按直角显示，开关均为关闭。
- 清理结果在下一次正常保存时持久化，不额外触发一次自动保存请求。
- 用户载入后人工开启的圆角不再属于旧数据，按正常编辑流程写入并保留。

## 预览行为

元素叠加预览仅对 `image` 和 `component` 应用用户载入后人工设置的正圆角。其他类型始终按直角显示。

## 测试范围

1. 自动检测得到的节点不含 `style.borderRadius`。
2. 载入数据时清除所有类型的旧圆角值。
3. 旧 `image`、`component` 数据载入后开关关闭且预览为直角。
4. `image` 和 `component` 显示圆角开关。
5. 首次人工开启圆角写入 `8px`。
6. 关闭圆角删除字段并恢复直角预览。
7. 其他元素类型不显示圆角入口且始终按直角预览。
8. 下一次正常保存持久化已清理的旧圆角数据。

## 非目标

- 不重新设计四角独立圆角。
- 不修改最终 HTML/CSS 生成逻辑；该功能尚未实现。
- 不删除圆角测量函数及其独立测试。
