# 动态多区域详情节点设计

## 目标

将当前唯一的“区域详情”节点改为按区域动态创建的多节点模型。用户点击某个区域时，画布为该区域创建独立详情节点；再次点击同一区域时定位并高亮已有节点，不重复创建。每个区域列表行与自己的详情节点建立独立连线。

## 交互规则

1. 分析完成后不自动创建详情节点。
2. 点击尚未打开的区域时：
   - 创建该区域的详情节点；
   - 在工作区右侧可用位置放置节点，避免与已有详情节点重叠；
   - 从对应区域列表行右侧端口连接到详情节点输入端口；
   - 自动将新节点平移到可见范围并高亮。
3. 点击已经打开的区域时：
   - 不创建重复节点；
   - 自动平移画布，使已有节点进入视口；
   - 短暂高亮该节点。
4. 多个详情节点同时存在，可独立拖动、查看、解析和编辑。
5. 删除详情节点后，该区域恢复为未打开状态；再次点击时重新创建。
6. 区域列表滚动、画布缩放或平移、节点拖动后，连线仍与对应区域和详情节点保持对齐。
7. 分析结果被整体替换时，移除已不存在区域对应的节点；仍存在的区域按区域 ID 保留节点及位置。

## 状态模型

画布状态从固定 `detail` 节点扩展为动态区域节点：

- 固定节点：`workspace`。
- 动态详情节点 ID：`detail:<regionId>`。
- 每个动态节点记录：
  - `regionId`
  - 画布世界坐标 `position`
  - 是否处于定位高亮状态
- 打开的区域集合以 `regionId` 唯一索引，保证一个区域最多对应一个详情节点。
- 节点位置按项目和区域持久化；无效或已删除区域的数据在加载后忽略。

DOM 元素与屏幕坐标不进入业务 store。区域列表只负责提供区域行锚点；画布负责将锚点转换为世界坐标并绘制连线。

## 组件职责

### `RegionList.vue`

- 保留现有区域选择行为。
- 为每行显示右侧连接端口。
- 通过已存在的 `rowRefs` 提供指定区域行的 DOM 锚点。
- 列表滚动或尺寸变化时通知上层重新测量连线。

### `RegionsNode.vue` 与 `App.vue`

- 将区域点击意图转为“打开或定位详情节点”。
- 转发区域行锚点访问能力和布局变化通知。
- 不保存 DOM 坐标。

### `PipelineCanvas.vue`

- 管理动态详情节点集合、位置、拖动、删除、定位和高亮。
- 为每个打开区域渲染一个 `PipelineNode` 和对应 `DetailNode`。
- 将列表行的屏幕坐标转换为画布世界坐标。
- 绘制 `区域列表行 → detail:<regionId>` 连线。
- 根据已有节点布局计算新节点的非重叠位置。

### `DetailNode.vue`

- 从“接收选择数组”调整为接收单个明确区域。
- 每个实例独立维护区域解析和编辑交互。
- 节点关闭由画布容器处理，详情内容不管理画布生命周期。

## 连线坐标

连线起点取对应列表行右边缘的垂直中心，终点取对应详情节点左侧输入端口。列表行的屏幕坐标按当前画布视口换算为世界坐标：

```text
worldX = (screenX - canvasLeft - viewportX) / zoom
worldY = (screenY - canvasTop  - viewportY) / zoom
```

使用现有三次贝塞尔路径算法。通过选择变化、列表滚动、`ResizeObserver`、窗口尺寸变化及节点拖动触发重算；高频事件使用 `requestAnimationFrame` 合并。

区域行端口属于工作区节点内部，因此工作区节点拖动时，DOM 测量结果自然随之变化。

## 节点布局与定位

- 第一个详情节点默认放在工作区右侧。
- 后续节点优先向下排列；空间不足时换列。
- 新节点位置需要避开所有已打开详情节点的边界并保留固定间距。
- 定位已有节点时保持当前缩放比例，仅调整平移量，使节点居中或完整进入安全视区。
- 高亮采用短暂的边框或阴影状态，不改变节点数据。

## 代码产出节点

本次范围聚焦多详情节点与区域连线。现有唯一代码产出节点不扩展为多实例，也不作为本次验收条件。后续可基于相同动态节点模型，为每个区域详情独立创建代码产出节点。

## 删除与异常处理

- 详情节点标题栏提供关闭操作。
- 删除只关闭画布节点，不删除区域分析数据。
- 若区域在重新分析后消失，对应详情节点和连线自动清理。
- 如果暂时无法取得列表行 DOM，保留详情节点但不绘制该条连线；下一次布局测量成功后恢复。
- 节点位置持久化失败不阻断交互。

## 测试范围

1. 点击未打开区域创建唯一详情节点。
2. 点击已打开区域不重复创建，并触发定位和高亮。
3. 多个区域可同时显示独立详情节点。
4. 每条连线起点对应正确区域行，终点对应正确详情节点。
5. 列表滚动、画布缩放和平移、节点拖动后连线保持对齐。
6. 删除节点后再次点击可重新创建。
7. 重新分析后清理失效区域节点并保留仍有效节点。
8. 动态节点位置可保存和恢复，损坏的持久化数据安全回退。
9. 单个详情节点的解析、编辑和 AI 交互不影响其他详情节点。
