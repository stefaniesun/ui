# Canvas UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变服务端、store 公开接口和坐标函数的前提下，把区域拆分 UI 重构为可平移缩放的深色流水线节点画布。

**Architecture:** 手写固定拓扑画布，避免为不可编辑的四节点图引入通用图编辑器。`PipelineCanvas` 独立维护平移、缩放、节点位置和连线；四个节点仅消费现有 store；`RegionCanvas` 延续现有坐标换算与拆分交互，节点内按原图尺寸渲染并由画布 zoom 统一缩放。

**Tech Stack:** Vue 3、TypeScript、Vite、Vitest、CSS/SVG，无新增第三方依赖。
