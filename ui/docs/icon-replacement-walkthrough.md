## 双向操作验证

对 `2.1 消息` 完成以下真实操作：

1. 打开“挑选图标”，原图裁片固定显示在左侧。
2. 右侧搜索 `chat`，本地图标库返回 24 个 SVG 候选。
3. 选择 `mdi:chat-outline` 并确认。
4. API 读取到：`kind=library`、`iconId=mdi:chat-outline`、`by=human`。
5. 再次打开弹框并点击“用原图切片”。
6. API 读取到：`kind=crop`、原 `assetRef` 保留、`by=human`。
7. 再搜索并恢复 `mdi:chat-outline`，最终项目保持人工确认的库图标结果。

这证明“库图标替换”和“恢复原图裁片”均已贯通现有保存链路，不只是临时 UI 状态。

## 验收结论

- 无有效英文关键词时不会发送空泛图标决策请求，而是进入明确的人工确认状态。
- 弹框展示原图裁片、初始候选、英文搜索结果和无结果提示。
- 用户可以明确选择库图标，也可以明确保留原图裁片。
- 人工选择可持久化，并影响生成页面资产。
- “待确认”“使用原图裁片”“已选择库图标”三种结论在属性面板中可区分。
